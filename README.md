Site portfolio personnel, one-page, présentant mon parcours d'étudiant ingénieur en Cybersécurité et Infrastructures Réseaux à l'EMSI, ainsi que mes projets techniques.

🔗 **Live :** https://alahyaneyassine.github.io/portfolio/

## À propos

Étudiant ingénieur en 5ᵉ année à l'EMSI (Casablanca), spécialisation Cybersécurité et Infrastructures Réseaux.

Le site présente :
- Mon parcours (formation, stages)
- Mes compétences techniques (réseaux, sécurité, développement web, ML)
- Mes projets (PFE réseau sécurisé FortiGate, PFA détection de fichiers malveillants, applications web)
- Un formulaire de contact (via Formspree)

## Stack

- HTML / CSS / JavaScript vanilla (fichier unique, sans build)
- Police [JetBrains Mono](https://www.jetbrains.com/lp/mono/) + [Inter](https://rsms.me/inter/) via Google Fonts
- Formulaire de contact géré par [Formspree](https://formspree.io/)

## Lancer en local

Aucune dépendance ni build nécessaire :

```bash
git clone https://github.com/AlahyaneYassine/portfolio.git
cd portfolio
# ouvrir index.html dans un navigateur, ou :
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## Déploiement

Le site est prévu pour être hébergé via **GitHub Pages** :
1. Settings → Pages
2. Source : `Deploy from a branch`
3. Branch : `main` / `root`
4. Le site sera disponible à `https://alahyaneyassine.github.io/portfolio/`
